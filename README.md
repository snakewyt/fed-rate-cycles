# 加息、降息与资产周期

把 1954 年以来的有效联邦基金利率分成加息、降息和持稳，对照标普 500、黄金、沪深 300、纳斯达克、罗素 2000，以及用 10 年期收益率估算的国债总回报。每一轮都给出累计收益、年化收益和段内最大回撤。页面会用上一轮加息或降息，写明现在大致是哪一种周期。

打开 `web/index.html` 即可看。更新数据后双击 `更新数据.bat`，或在这个目录运行：

```bash
py -3 build.py
```

不重新下载、只用本地缓存时：

```bash
py -3 build.py --offline
```

明细表同时写在 `data/cycles.csv`。

## 周期怎么划

利率用美联储 H.15 的月平均有效联邦基金利率。

- 从阶段低点回升满 **1.00** 个百分点，确认加息开始；从阶段高点回落满同样幅度，确认降息开始。
- 若之后利率离这个高点或低点不超过 **0.25** 个百分点，并且持续满 **9** 个月，这一段标成持稳。零利率年、加息见顶后的平台，不会整段算进降息或加息。
- 还没被反向 1 个百分点确认的最后一段，标成进行中。中位数不含进行中的这一轮。持有期不足 6 个月的不计算年化。

参数在 `build.py` 顶部。

## 数据

- 联邦基金利率、10 年期国债收益率：美联储 [H.15](https://www.federalreserve.gov/releases/h15/) 月平均。
- 标普 500：罗伯特·席勒的月平均价，覆盖 1954 年以来每一轮；席勒序列结束后的月份用 Yahoo 月收盘接上。两者重叠月份的中位比大约是 1.01。
- 黄金：美元/盎司月平均现货价，从 1968 年起。更早是官价，那些周期的黄金列是空的。
- 沪深 300：月收盘，从 2005 年起。更早的周期这一列是空的。价格指数，不含分红。能对上的加息、降息轮次不多。
- 纳斯达克综合、罗素 2000：Yahoo 月收盘，分别从 1985 年和 1987 年开始。更早的周期这两列是空的。
- 10 年国债：不是债券指数。按每年付息的 10 年平价债，用久期和凸性把收益率变化滚成近似总回报。
- 股票是价格，不含分红。长周期会比总回报少掉分红那一截。

只需要 Python 3.9 以上，不安装第三方包。下载用系统里的 `curl`。
